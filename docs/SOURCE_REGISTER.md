# Source Register & Open Diligence

This is the working source register for the 1011 N B Street homeowner playbook. Verify live rules, fees, listings and lender terms before acting because those can change.

## Coeur d’Alene code / City sources

Key code topics used in the strategy:

- R-12 minimum lot area / frontage — CDA Municipal Code §17.05.230.
- R-12 yards / setbacks — §17.05.240.
- Frontage definition — §17.02.055.
- Boundary line adjustments — Title 16 BLA provisions, including §§16.10.020–.030.
- Formal vs short subdivision — §16.05.030.
- Subdivision frontage / access — §16.15.160.
- Pre-1960 demolition review — §2.85.055 and related Building/HPC provisions.
- Current ADU standards — §17.06.660.

City process sources:

- Coeur d’Alene Boundary Line Adjustment application / Engineering instructions.
- City-wide fee schedule. Prior reviewed figures included approximately $750 for Engineering BLA processing, $350 preliminary-plat preapplication, $1,000 preliminary short subdivision, and $60 zoning verification. Recheck the current fee schedule before filing.
- Planning zoning-verification process.
- Building permit search.
- Wastewater GIS / sewer-lateral information and 811 locate guidance.

## Evidence-quality rule

GIS and aerial parcel overlays are planning graphics only. They do not establish ownership boundaries, setbacks or encroachments. The licensed survey, title record and written City determination control the decision.
