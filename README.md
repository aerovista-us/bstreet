AeroVista research workspace for the owner of **1011 N B St, Coeur d’Alene, Idaho (APN C3510003001A)**.

## Purpose

This repository is the lightweight, source-controlled edition of the homeowner decision guide. The research strategy is to prove the high-value subdivision/frontage opportunity with the least possible owner cash, then choose the exit that best eliminates the mortgage while preserving equity.

Current preferred path, if the survey/City/title work is green: **split → sell the house-side parcel → pay off the mortgage → retain the buildable lot**.
